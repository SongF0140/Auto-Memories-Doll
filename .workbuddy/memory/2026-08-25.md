### 5. 记忆标题清洗系统 (`title-sanitizer.ts`)
新建 `src/lib/utils/title-sanitizer.ts`，提供：

| 函数 | 功能 |
|------|------|
| `sanitizeTitle(raw)` | 清洗单条标题 |
| `extractCleanTitle(text)` | 从文本提取干净标题 |
| `sanitizeTags(tags)` | 清洗标签列表 |

**清洗规则：**
- 移除控制字符（\x00-\x1F, \x7F）
- 去除首尾无意义符号（–—~*#·•●○■□►▶ 等）
- 压缩连续标点（最多保留2个）
- 跳过纯 emoji 行
- 清理 Markdown 链接/图片语法、HTML 标签、代码块
- 跳过元数据行（date/time/author 等）
- 截断过长标题（60字符，保持中文完整性）
- 确保非空且有实际内容

**集成到 `MemoryExtractor`：**
- `extractFromText()` → 使用 `extractCleanTitle()`
- `extractFromStructuredData()` → 使用 `sanitizeTitle()`
- 标签输出 → 使用 `sanitizeTags()`
