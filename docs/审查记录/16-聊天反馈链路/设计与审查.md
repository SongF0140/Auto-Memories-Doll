## 交付内容（4 个新文件 + 3 个改动）

1. **新 API** [learning-tasks/route.ts](file:///D:/agent_road/Auto-Memeries-Doll/src/app/api/chat/learning-tasks/route.ts)：`GET ?sessionId=` 返回该会话学习任务状态摘要。**脱敏边界**：只回 turnId/status/resultSummary/knowledgeCount/reconciliation 计数，不回 result_json 正文——私人对话内容不经轮询通道外泄。

3. **新组件** [LearningStatusBar.tsx](file:///D:/agent_road/Auto-Memeries-Doll/src/components/chat/LearningStatusBar.tsx)：输入栏上方状态条，role="status" + aria-live。文案诚实分级：queued「排队中，等待后台分析」/ processing「正在分析」/ completed「已沉淀 N 卡 · M 张待确认 · X 条重复」+ 待确认>0 时给「前往审核」（/audit）入口 / failed 带原因。**绝不把 queued 说成已保存**（验收点 261）。
4. [useChatSession.ts](file:///D:/agent_road/Auto-Memeries-Doll/src/components/chat/useChatSession.ts)：state 增 `sessionMeta`（title/updatedAt 表），restoreSession 与 refreshSessions 双路填充。
5. [ChatInterface.tsx](file:///D:/agent_road/Auto-Memeries-Doll/src/components/chat/ChatInterface.tsx)：会话标签由 `id.slice(5,13)` 纯 ID 改为**标题 + 日期**（无标题回退 ID 片段，hover 显示完整标题+时间）；消息流尾部挂状态条。

## 设计取舍

- 轮询而非推送：项目无 SSE 任务通道，5s 轮询 + 终态停止成本可控。
- 状态条挂会话级而非消息级：learning 任务以 turn 为单位，消息级映射需消息含 turnId（现无），落点选会话级最新任务，语义诚实。
- 会话标题来自服务端 SessionSummary.title（已有字段），前端不再自行生成，避免两端不一致。
